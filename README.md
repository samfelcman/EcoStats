# EcoStats
Um site que monitora a economia dos paises em tempo real.

O EcoStats é um dos meus projetos mais ambiciosos, quero transforma-lo em uma verdadeira potencia para o uso de capitalização global, não será apenas um software, e sim, uma grande amostra de como podemos ter mais controle sobre nossos gastos mundias, permitindo uma melhor aceitação e melhorar como os paises e estasticas deles podem revolucionar o ambiente politico e geografico.
