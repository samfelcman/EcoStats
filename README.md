# EcoStats
Um site que monitora a economia dos paises em tempo real.

O EcoStats é um dos meus projetos mais ambiciosos, quero transforma-lo em uma verdadeira potencia para o uso de capitalização global, não será apenas um site, e sim, um software com uma grande amostra de como podemos ter mais controle sobre nossos gastos mundias, permitindo uma melhor aceitação e melhorar como os paises e estasticas deles podem revolucionar o ambiente politico e geografico.

Por enquanto foram introduzidas apenas o JavaScript e como foi utilizado o Claude para montar a base do codigo, estou realizando conhecimentos de clean code, segurança contra ataques e modificando o front e atualizando o back.

o que o projeto faz ate agora:
- Controla o PIB dos paises em escala global e em tempo real, alguns paises estão com informações erradas e desuatalizadas, farei a consulta na API para averiguar.
- Comparador de moedas: basicamente você escolhe o paises em que deseja comparar a moeada e valorização da mesma e é mostrado em tempo real.
- Globo interativo: esse é o escopo principal do projeto, possui um globo da terra totalmente imersivo e interativo, onde é só você clicar no pais que deseja.
